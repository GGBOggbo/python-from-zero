# python-from-zero

10天学会 Python，运维/LLM 工程师速成指南。

## 特色

- **10 天课程**：从变量到模块，循序渐进
- **代码编辑器**：内置编辑器，直接在浏览器运行 Python 代码
- **参考答案**：每道练习题附参考答案，点击即可查看
- **暗色/亮色主题**：支持主题切换，护眼学习

## 快速开始

```bash
# 启动服务器
cd python
python3 server.py

# 浏览器打开
open http://localhost:8888
```

## 课程大纲

| 天数 | 主题 | 关键内容 |
|------|------|----------|
| Day 1 | 变量和数据类型 | 字符串、数字、f-string |
| Day 2 | 字符串操作 | 切片、split/join、格式化 |
| Day 3 | 列表 | 增删改查、列表推导式 |
| Day 4 | 字典 | 嵌套字典、遍历、合并 |
| Day 5 | 条件判断 | if/elif/else、逻辑运算 |
| Day 6 | 循环 | for/while、break/continue |
| Day 7 | 函数 | 参数、返回值、kwargs |
| Day 8 | 文件操作 | 读写文件、路径处理 |
| Day 9 | 异常处理 | try/except、自定义异常 |
| Day 10 | 模块和 import | 标准库、第三方库 |

## 技术栈

- 前端：原生 HTML/CSS/JS
- 代码执行：Python subprocess（服务端）
- 代码高亮：highlight.js
- 字体：Inter + JetBrains Mono
