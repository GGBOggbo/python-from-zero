# python-from-zero

30天学会 Python，运维/LLM 工程师速成指南。

## 特色

- **30 天课程**：从变量到 RAG 知识库问答系统，循序渐进
- **代码编辑器**：内置编辑器，直接在浏览器运行 Python 代码
- **参考答案**：每道练习题附参考答案，点击即可查看
- **暗色/亮色主题**：支持主题切换，护眼学习

## 快速开始

```bash
# 启动服务器
python3 server.py

# 浏览器打开
open http://localhost:8888
```
